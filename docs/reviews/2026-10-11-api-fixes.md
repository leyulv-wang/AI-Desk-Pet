# API 日常使用审查修复

日期：2026-10-11。按用户要求直接处理，不保留旧 DDSP 管线作为运行依赖。

## 已处理

- 本地协议改为公开资源白名单：只开放界面、Live2D 库、模型图片与指定音频缓存。配置、主进程源码、聊天与记忆数据无法通过该协议读取，包含开发数据目录。
- 音频使用固定同源路由 `pet://app/audio/tts/` 与 `pet://app/audio/singing/`，缓存放到项目外仍可播放。
- MiniMax／MiMo 缓存包含实际后端参数、音色、情绪、样本内容与后处理设置。生成期间热更新不会把新参数结果写入旧缓存。
- 非流式 API 的超时覆盖响应头与完整响应体。聊天停止会取消正在合成的语音请求，取消后不写入或播放迟到的音频。
- 角色表情独立于自动朗读开关，优先使用模型给出的情绪标签。
- 静态角色不创建 Pixi 舞台，也不加载 Live2D 运行库。切换到 Live2D 才按顺序加载依赖。
- 唱歌模块替换为 MiniMax music-cover API，包含内容与配置缓存、明确的权限错误、取消和播放路径。界面移除 Python 环境安装提示。
- 删除旧 DDSP／RVC 管线、相关工具和安装命令。保留未纳入 Git 的个人歌曲、模型、旧环境与历史数据，继续忽略这些目录，避免误上传。

## 验证和边界

`npm test` 包含逻辑回归、API 生命周期测试和 Electron 界面测试；接口测试使用模拟响应，不上传个人音频、不消耗付费额度。静态界面测试主动拒绝提供 Live2D 库。

云端翻唱参考音频会发送给服务商。停止仅保证本地不再等待、发布或播放结果，不能保证远端计算及计费被撤销。音乐接口权限、余额、音质和音色需要真实账号验证。

[MiniMax 官方音乐 API](https://platform.minimax.cn/docs/api-reference/music-generation)支持音频参考翻唱，但没有说话 voiceId 参数，不能保证与说话的克隆音色一致；文档也声明对新账号限制开放。

本次没有制作 Windows 安装包。图形化 API 设置、打包、升级和资源管理留待下一轮日常软件迭代。
